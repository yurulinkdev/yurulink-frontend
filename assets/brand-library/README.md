# YuruLink ブランド素材

2026-11-24採用B案（内側 #F4EFE7、外形 #A35B46、外部透過）。Driveの[メイン素材](https://drive.google.com/drive/folders/1z1TxI3rFtrHUTL3TkxlkeeXTTTMK80Oq)と[用途別画像](https://drive.google.com/drive/folders/1nfiIK8g5WtwiTZAcNGFow9uvgnf8aXj8)の最新版。単色のSVG/1024pxと採用JPEGは基礎素材として維持。制作履歴や旧版ZIPは含めない。

編集はAutomationLabのHTML/CSS/SVG、画像化はPlaywright Chromium。manifest.jsonにDrive ID・Git blob SHAと公開用staticの対応を記録。既存公開パスは維持し、静的ファイルは同一blobに同期する。Xヘッダー・SNSアイコンとフォームは素材保存のみ、外部サービスへの適用は別工程。ダークOGPは代替版で既定のOGPはライト。mainへの反映は別途承認。
