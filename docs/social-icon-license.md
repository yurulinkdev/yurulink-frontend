# SNSアイコンの出典と利用方法

- アイコン： [Simple Icons](https://simpleicons.org/) 由来のローカルSVG（x, instagram, youtube, bluesky, threads, discord, tiktok, facebook）。
- 取得元： https://github.com/simple-icons/simple-icons/tree/develop/icons （2026-11-21参照）。
- 配布形態：CDNではなく本リポジトリの static/icons/social/ に配置。サイト起動時の第三者へのアクセスを発生させない。
- Simple Iconsのリポジトリ本体はCC0-1.0。**ただし、ブランドロゴに個別の商標・ライセンス条件がある場合はそちらが優先する**。公式の DISCLAIMER.md を必ず確認すること。
- アイコンをYuruLink自体の商標・提携表示と誤認させないため、サイト上のURLで対応する外部サービスへのリンクのみ表示する。ブランドアイコンの形状は編集せず、ダークテーマ向けの単色反転のみCSSで行う。
- CTAの外部リンク表記・aria-labelではアイコンを装飾扱いにし、テキスト名を必ず併記する。
