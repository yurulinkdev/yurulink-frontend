# YuruLink デザインシステム

## 基本方針

動画・サイト・SNSを探すための検索とカテゴリメニューを中心に配置します。PCは情報密度を確保し、スマートフォンは一列表示と操作しやすいナビゲーションを重視します。サイトが関連番組の**非公式リンク集**であることを誤認させない表示にします。

## カラーとテーマ

| 意味 | 基本色 |
| --- | --- |
| アクセント | `#A35B46` |
| 背景 | `#FBF9F6` |
| 文字 | `#342B28` |

色は意味別のCSS変数で管理し、`assets/css/tokens.css`と`assets/css/input.css`へ集約します。ライト／ダーク／OS追従のテーマを提供します。十分な文字コントラスト、フォーカス状態、WCAG 2.2 AAを考慮します。

## ロゴと画像

採用したブランドシンボルは開いた本をモチーフとし、`hugo.toml`の`params.brand_logo`から`static/brand/`以下のSVGへ参照します。ファビコン、Apple Touch Icon、OGPライト／ダーク画像は`static/`に配置します。ブランド制作原本・生成用素材はGoogle Driveの`YuruLink_Assets`で管理し、配信する画像と混同しません。

サムネイルはカード・リストとも**16:9の表示枠**とし、`object-fit: cover`で縦横比を維持します。カードでは枠いっぱいに配置、リストではPC`168×94.5px`、スマホ`128×72px`とします。YouTube側の元画像に含まれる帯は表示枠で中央トリミングします。SNSの円形アバターは別ルールです。

## タイポグラフィ

Webフォントへの必須依存を置かず、日本語システムフォントを優先します。

| 用途 | CSSトークン・クラス | 基本値 |
| --- | --- | --- |
| 本文、検索、ナビ | `--font-ui` | 16px、400、行間約1.7 |
| ワードマーク | `--font-brand`／`.brand-wordmark` | 20px、700 |
| 小見出し・メニュー | `--font-ui` | 14px、600〜700 |
| カードの補足 | `--font-ui` | 13px前後（コンパクト表示は小さめ） |

フォントスタックはOSに応じたHiragino Sans、Yu Gothic、Noto Sans JP等のフォールバックを利用します。文字列を画像に焼き込まない場面ではHTMLテキストとして保持します。

## コンポーネント・共通操作

- PCは左サイドバー、モバイルはドロワー。共通Hugo部分テンプレートでカテゴリを管理し、下層ページも同じナビを用います。
- カード／リストを切り替え、利用者の選択をブラウザに保持します。コンテンツが複数所属しても同一Itemを重複公開しません。
- ブランドロゴまたは「すべてのコンテンツ」は選択カテゴリを解除します。他の表示設定や展開状態は保持します。
- スキップリンク、意味のある見出し、操作ボタンの`aria-label`、キーボードフォーカス、Escapeによるドロワー閉鎖、`prefers-reduced-motion`を尊重します。
- ドロワーのスワイプ閾値、カテゴリ保存、更新履歴URL、カードの表示寸法は[UI回帰仕様](frontend-ui-regression-contract-20261122.md)で一意に定義します。

## 性能と検証

静的ビルドと必要最小限のJavaScriptを基本に、表示対象ページの画像・メタ情報を優先して処理します。`loading=lazy`、画像寸法と`sizes`、画面外描画抑制、初期表示のLCP・INP・CLSを検証対象とします。操作時のDOM更新件数と初期HTMLの転送量を別々に計測します。

参照：[Frontend分類・性能契約](frontend-refactoring-performance-category-20261122.md)／[WCAG 2.2](https://www.w3.org/TR/WCAG22/)／[Core Web Vitals](https://web.dev/vitals/)。
