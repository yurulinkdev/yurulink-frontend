# YuruLink デザイン仕様

**状態：基本方針決定済み。** 最終ロゴ、詳細なアクセシビリティ検証、実データでの性能検証は未完了です。

## デザインの基本方針

- **親しみやすい知識ライブラリ**を目指す。
- ホームページはリンク集を主役とし、検索・カテゴリー・表示切替を見つけやすくする。
- PCは情報密度を高め、スマートフォンは読みやすさを優先する。
- 既存サイトの配色をそのまま引き継がず、ニュートラルな基調と温かいアクセントを用いる。

## 色とテーマ

採用する方向性は**ウォームテラコッタ**です。

| 用途 | 色 |
| --- | --- |
| アクセント | `#A35B46` |
| 背景 | `#FBF9F6` |
| 文字 | `#342B28` |

色はコンポーネントに直接埋め込まず、意味別のCSS変数で管理します。ライト／ダーク／OS自動追従を提供し、ダーク配色は独立して設計します。文字とUIのコントラストはWCAG 2.2 AAを目標に検証します。

## ロゴ・アイコン

**幾何学的な開いた本**をシンボルの方向性として採用します。現在のSVGは暫定版です。番組公式との関係を誤認させないデザインとし、単色表示や小さなファビコンでも判別できる形を目指します。

## 文字・レイアウト

- 日本語のシステムフォントを優先し、必須の外部Webフォントは使用しません。
- 本文の基準は16px、行間は約1.7。補足情報は13〜14pxを目安とします。
- スマートフォンは1列、タブレットは2列、PCは3列または可変密度のカード表示を基本とします。
- PCは左サイドバー、スマートフォンはドロワーを使用します。
- カードにはカテゴリー／掲載先、タイトル、短い説明、任意の公開日・サムネイルを表示します。
- **カード表示とコンパクトなリスト表示を切り替え可能**にし、選択をブラウザに保存します。
- サムネイルの有無でレイアウトが崩れないよう表示領域を確保します。
- サムネイルは共通16:9枠を余白なく満たす。YouTube hqdefaultの内蔵黒帯を見せず、画像比率を変えない `object-fit:cover` を利用。リスト幅はPC 168px・スマホ128pxを固定。詳細は [2026-11-22のUI回帰防止契約](frontend-ui-regression-contract-20261122.md) を正本とする。

## ページ構成

共通部分はスキップリンク、ヘッダー、ナビゲーション、本文、フッターです。ホームは検索・カテゴリー・リンク集を中心とし、記事／お知らせは補助的に配置します。HugoのMarkdown記事は公開カタログがない場合も表示可能とします。

## アクセシビリティ・性能

- キーボード操作、フォーカス表示、ドロワーのEscape操作、見出し階層、代替テキストを検証します。
- `prefers-reduced-motion` を尊重し、過度なアニメーションを避けます。
- 320px、375px、768px、1280pxを代表的な表示幅として確認します。
- 外部アイコンフォントや埋め込みSNSタイムラインは必須にしません。Xは通常リンクで扱います。
- 画像は遅延読み込み・寸法指定を基本とし、WebP/AVIFの利用を検討します。
- 数千件を初期DOMへ一括描画せず、分割表示やPagefind等の検索方式を検証します。
- GA4は明示設定とプライバシー要件の確認が完了するまで無効とします。

## 書体・タイポグラフィの統一規則（2026-11-19）

既存の「システム和文サンセリフを優先し、必須の外部Webフォントを使わない」という方針を正式な実装ルールとして固定する。

| 用途 | CSS参照／指定 | サイズ・ウェイト |
| --- | --- | --- |
| 本文・検索欄・ナビゲーション | `--font-ui` | 基本16px、通常400、行間1.7 |
| YuruLinkワードマーク（HTMLテキスト） | `--font-brand`、`.brand-wordmark` | 20px、700、字間 -0.02em、行間1.2 |
| 小見出し・メニューラベル | `--font-ui` | 原則14px、必要時600〜700 |
| 注記・カードのメタ情報 | `--font-ui` | 13pxを目安（コンパクトリストは11〜12pxまで縮小可） |
| 媒体別画像の文字 | 共通フォント規則を参照し、HTML/CSSで組版 | 見出し・本文ごとにスタイルを分離 |

- CSSトークンは `assets/css/tokens.css` の `--font-ui`、`--font-brand`、`--type-*`。適用は `assets/css/input.css` に集約する。
- フォントスタックは和文：`system-ui / -apple-system / Hiragino Sans / Yu Gothic / Noto Sans JP / Meiryo / sans-serif`。欧文ブランド：`system-ui / -apple-system / Segoe UI / sans-serif`。OSごとに実際のグリフ形状が異なる点は既知の制限。厳密なブランド形状固定が必要になった時点で、フォントの利用許諾・配信サイズを評価して別途採用判断する。
- ブランドシンボルはSVGアイコンフォントで代用せず、`static/brand/yurulink-symbol-approved-transparent.png`（承認原本JPEGから背景を透過した画像）を使用。サイト名「YuruLink」は文字列としてHTMLに保持するため、検索・拡大・読み上げ可能。
- ダークテーマでもテキストの色は`text-accent`トークンで切り替える。ブランドシンボルの色は元のデザインを保持する。
- アイコンはTailwind CSSの機能ではない。使用する小型UIアイコンは同開発元のHeroicons（MITライセンス）のoutlineスタイル24pxを標準とし、SVGをインラインで配置する。アイコンのみのボタンには`aria-label`を必須とする。現在の閉じるボタンには`arrow-left`を採用した。
- 正式ブランド画像・関連資料: Google Drive `YuruLink_Assets/02-selected`、`Image-Prompts.md`。favicon／OGPのデザイン承認状態とは区別する。
